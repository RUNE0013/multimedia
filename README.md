# マルチメディア検定 ベーシック対策ドリル

CG-ARTS「マルチメディア検定 ベーシック」の出題範囲（第1問〈共通問題〉＋第34〜42問の9分野）に沿った、オリジナル練習問題のWebアプリです。ビルド不要の静的サイトなので、GitHub Pages でそのまま公開できます。

## 機能

- **模擬試験**：本番と同じ構成（共通4問＋9分野×4問＝40問／60分）。最後にまとめて採点し、100点換算と分野別の正答を表示
- **分野別演習**：1問ずつ解答・解説を確認
- **クイック演習**：ランダム10問／未回答から10問
- **苦手克服**：直近で間違えた問題だけを出題
- **学習記録**：分野別の正答率と履歴（ブラウザの localStorage に保存）
- 選択肢は出題のたびにシャッフル、キーボード操作（1〜7で選択、Enterで次へ、←→で移動）、ダークモード対応

## 公開手順（GitHub Pages）

1. このリポジトリを GitHub に push
2. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

ローカルで確認する場合は `index.html` をブラウザで開くか、`python -m http.server` で起動してください。

## 問題データ

`data/questions/<分野>.js` に分野ごとに格納しています。

| ファイル | 分野 |
|---|---|
| ip.js | 第1問〈共通〉知的財産権 |
| image.js | 第34問 画像や色 |
| feature.js | 第35問 マルチメディアの特徴 |
| content.js | 第36問 コンテンツの処理と制作 |
| device.js | 第37問 マルチメディア端末 |
| net.js | 第38問 インターネットと通信 |
| service.js | 第39問 インターネットのサービス |
| business.js | 第40問 インターネットビジネス |
| security.js | 第41問 セキュリティと情報リテラシ |
| society.js | 第42問 社会に広がるマルチメディア |

問題の形式：

```js
{ id: "net-001", cat: "net", type: "single", q: "問題文", choices: ["…", "…", "…", "…"], answer: 2, exp: "解説" }
// type: "combo"  … 「①②に適する組み合わせ」。問題文の空欄は【①】のように書く
// type: "multi"  … 「正しいものをすべて選んだ組み合わせ」。statements（3つ）と answer（正しい文のインデックス配列）
// fixed: true    … 選択肢の順序に意味がある問題（数値の昇順など）はシャッフルしない
```

## 注意

- 本アプリの問題は、公式の出題範囲・形式を参考に作成したオリジナル問題です。公式の過去問題の本文は含みません。
- 公式の過去問題は [CG-ARTS 過去問題ダウンロード](https://www.cgarts.or.jp/kentei/past_download/) から入手できます（著作権は CG-ARTS に帰属）。
